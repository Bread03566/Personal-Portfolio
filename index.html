ACES LMS

A short walkthrough of ACES LMS.

Problem it solves
A college needs one system where students, teachers, and administrators each get the tools for their own job: lessons and quizzes, grading and approval, and school setup.
My role
Developer on our thesis team, working across the full stack.
Key features
  • Four portals: student, teacher, admin, and system admin
  • Lessons, quizzes, and activity submissions
  • Gradebook with an admin approval step before grades are final
  • Programs, sections, and teaching-load setup
  • Audit log, system health, and AI usage tracking for system admins
  • Session authentication with email OTP
Built with
  • React 19
  • React Router
  • Vite
  • Tailwind CSS
  • Laravel 12
  • MySQL
  • Docker
  • Cloudflare R2
  • PHPUnit
